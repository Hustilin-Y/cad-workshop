# Калибровка допусков

Образец `tolerance-gauge` (148 × 58 × 11 мм, около 21 см³, два тела на столе):

- **Пластина.** Сверху ряд из 11 отверстий диаметром `8 + c`, снизу ряд из 11 штырей диаметром `8 − c`. Между рядами подписаны значения `c`: `.00`, `.05` … `.50` мм. Зазор указан на диаметр.
- **Ключ.** На одном конце штырь ровно 8 мм, на другом кольцо с отверстием ровно 8 мм.

Собрать: `uv run cad.py build calibration`, файлы в `calibration/out/`.

## Печать

- Тем же пластиком, соплом и профилем, которыми будете печатать детали. Для каждого пластика допуски свои.
- Класть как есть, плоской стороной на стол. Поддержки не нужны.
- Не обрабатывать после печати: нужны допуски «как с принтера».

## Как читать результат

1. **Отверстия.** Вставляйте штырь ключа в каждое отверстие пластины.
2. **Штыри.** Надевайте кольцо ключа на каждый штырь пластины.

Для каждого ряда найдите три значения:

| Посадка | Признак | Ключ в `printer.toml` |
|---|---|---|
| Натяг (press fit) | входит с усилием, держится сам, без люфта | `press_fit_mm` |
| Скользящая (slide fit) | ходит рукой свободно, но почти без люфта | `slide_fit_mm` |
| Под винт/вал | входит свободно, с заметным люфтом, не заедает | `hole_clearance_mm` |

Напишите мне результат, например «отверстия: натяг .10, скользит .25, свободно .35; штыри: натяг .05, скользит .20». Я перенесу значения в `printer.toml`. Если для отверстий и штырей значения сильно разойдутся, заведу для них отдельные допуски.

Первые слои у отверстий обычно сужены («слоновья нога»). Если там туго, а выше свободно, ориентируйтесь на верх отверстия и сообщите об этом.
