# plant-lamp-bracket

Г-кронштейн для подвеса лёгкой лампы для растений (около 350 г) на карабин. Полка лежит на подоконнике и уходит вглубь, у её дальнего конца один потайной саморез 6 мм в подоконник. Стойка поднимается вверх, наверху отверстие под карабин. Две косынки в углу передают нагрузку со стойки на полку.

## Ключевые размеры

| Параметр | Значение | Откуда |
|---|---|---|
| Полка (вглубь подоконника) | 210 мм | задано пользователем |
| Стойка (вверх) | 150 мм | задано пользователем |
| Ширина | 50 мм | задано пользователем |
| Саморез | 1 шт., 6 мм, потай 90° **на внешней стороне полки** (без стойки), центр в 15 мм от дальнего конца | задано пользователем; головка Ø12 по DIN 7997 — **уточнить замером** |
| Отверстие под саморез | Ø6.6 (6 + 0.4 + зазор 0.2) | `fasteners.wood_screw_countersunk_hole` |
| Отверстие под карабин | Ø12, центр в 15 мм от верха стойки, фаски 0.8 с обеих сторон | задано пользователем |
| Толщина полки и стойки | 5 мм | по умолчанию: нагрузка 350 г |
| Косынки | 20 мм по полке × 33 мм по стойке, толщина 4 мм, по краям ширины | по просьбе пользователя втрое меньше первого варианта (60 × 100) |
| Скругления угла | R8 внутри, R13 снаружи | косметика и прочность |

Объём около 89 см³: примерно 115 г PETG.

Файлы для печати собраны с допусками PETG: `uv run cad.py build parts/plant-lamp-bracket --material petg`. Отверстие под саморез Ø6.65.

## Печать

- Пластик: **PETG**. Рядом с растениями влажно, лампа греет, а PLA под постоянной нагрузкой со временем ползёт.
- Ориентация (предложение): **как в модели, полкой на стол**. Площадь контакта со столом большая. Косынки поднимаются круче 45°, поэтому поддержки не нужны. Отверстие под карабин горизонтальное, Ø12 печатается без поддержек.
- Потай оказывается на нижней стороне, у стола. Это конус 45°, он печатается без поддержек. Кромку может слегка «подплавить» первым слоем (слоновья нога): если головка не сядет заподлицо, снимите наплыв ножом или пройдите сверлом-зенкером.
- При 350 г запаса прочности хватает. Если нужно ещё прочнее, кронштейн можно положить на бок: слои пойдут вдоль изгиба, но потай самореза тогда окажется сбоку.
