# rod-cap-thread-test

Тестовое кольцо Ø48 × 10 мм с той же резьбой, что у заглушки [rod-cap](../rod-cap). Печатается около 20 минут. Все параметры резьбы берутся из `parts/rod-cap/model.py`, поэтому правки там сразу попадают и в кольцо.

Накрутите кольцо на шпильку:

- идёт рукой, без люфта → печатайте заглушку;
- туго → увеличьте `slide_fit_mm` в `printer.toml` на 0.1–0.2 и пересоберите оба файла;
- болтается → уменьшите;
- не наживляется совсем → неверный шаг или диаметр, перемерьте шпильку.

Печатать тем же пластиком, что и заглушку, открытым торцом с фаской на стол.
