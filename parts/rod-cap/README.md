# rod-cap

Защитная заглушка на резьбовую шпильку около Ø38. Накручивается как гайка на 50 мм, сверху шар Ø60, чтобы ребёнок не поранился, ударившись о торец шпильки.

> **Примерная модель.** Диаметр и шаг резьбы взяты условно. Перед печатью замерить шпильку и сначала напечатать [тестовое кольцо](../rod-cap-thread-test).

## Ключевые размеры

| Параметр | Значение | Откуда |
|---|---|---|
| Резьба | Ø38, шаг 4, метрический профиль 60° | «около 38» со слов пользователя, шаг **условно** — замерить |
| Зазор резьбы | +0.35 мм к диаметру (PETG) | `slide_fit_mm` из `printer.toml` |
| Глубина накручивания | 50 мм (около 12 витков) | «сантиметров пять» со слов пользователя |
| Втулка | Ø48, стенка 5 мм под резьбой | по умолчанию |
| Шар | Ø60, центр в 67 мм от низа | по умолчанию |
| Полость над резьбой | +2 мм под неровный торец шпильки, потолок конусом 45° | печать без мостов |
| Заходная фаска | 1.5 мм | облегчает наживление |
| Габарит | Ø60 × 97 мм | |

Объём около 129 см³. Реальный вес с заполнением покажет Bambu Studio.

## Как уточнить резьбу

1. Штангенциркулем замерить наружный диаметр шпильки по вершинам витков и вписать в `THREAD_D`.
2. Посчитать витки на 20 мм длины: шаг = 20 / число витков. Вписать в `THREAD_PITCH`.
3. Профиль должен быть острый, треугольный (метрика или дюймовая). Трапецеидальная резьба (Tr) требует другого профиля, сообщить.
4. Собрать и напечатать `parts/rod-cap-thread-test`, накрутить на шпильку:
   - идёт рукой, без люфта → печатать заглушку;
   - туго → увеличить `slide_fit_mm` в `printer.toml` на 0.1–0.2;
   - болтается → уменьшить.

## Печать

- Ориентация: **шаром вверх, открытым торцом на стол**, как в модели. Резьба вертикальная и получается самой точной. Поддержки не нужны: потолок полости — конус 45°, низ шара нависает примерно на 37°.
- Пластик:
  - **TPU 95A** — мягкий, гасит удар. Для защиты детей это лучший вариант. Резьба в TPU сидит свободнее, для заглушки это не важно.
  - **PETG** — твёрдый, держит резьбу крепче, но удар не смягчает.
- Стенки: 3–4 периметра. Резьба целиком попадёт в периметры и будет прочной.
