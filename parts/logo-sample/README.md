# logo-sample

Пробная пластина ~104 × 52 мм с лого мастерской в двух стилях:

| | Барельеф | Контурный |
|---|---|---|
| 40 мм | слева | в центре |
| 20 мм | справа сверху | справа снизу |

- **Барельеф:** основа 0.8 мм. Бортик головы, маска и бабочка выше на 0.4, глаза, нос, узел и бортик бабочки ещё на 0.4. Пасть утоплена на 0.4, язык внутри.
- **Контурный:** стенки 1 мм по границам зон. Глаза и нос залиты.
- Бортики и стенки — 3% высоты лого, но не тоньше 0.8 мм (две линии сопла 0.4).

Лого лежит в [cadlib/logo.py](../../cadlib/logo.py):
- `logo_relief()` и `logo_outline()` — для печати;
- `logo_svg()` — цветная версия для наклеек;
- `render_colors()` — цветное превью.

Контуры сняты с картинки [assets/logo/shiba-styles-front.webp](../../assets/logo/shiba-styles-front.webp) скриптом `tools/logo_extract.py`.

## Печать

- Лицом вверх, слой 0.12–0.16 мм, ironing на верхних поверхностях.
- Без поддержек.
