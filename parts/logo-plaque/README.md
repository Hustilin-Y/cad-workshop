# logo-plaque

Табличка с лого мастерской: плитка 64 × 64 × 4 мм, углы R7, скос верхней кромки 0.8. На ней лого в стиле «барельеф» высотой 52 мм: основа 1.2 мм, шаг уровней 0.6. Лого — [cadlib/logo.py](../../cadlib/logo.py).

## Печать

- Лицом вверх, поддержки не нужны.
- Слой 0.12–0.16 мм, ironing на верхних поверхностях.

## История

- 2026-11-08: первая версия — гранёный рельеф по картинке пользователя.
- 2026-11-08: переведена на лого-штамп (low-poly контур + черты линиями): гранёный рельеф на деталях 2–4 см не читается, решили делать единое плоское лого.
- 2026-11-08: новое лого — мультяшная сиба в стиле «барельеф» по картинке пользователя.
