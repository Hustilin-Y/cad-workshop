# CAD-мастерская

Параметрические детали и ремиксы чужих моделей под 3D-печать на Bambu Lab P2S. Модели пишутся кодом (build123d, manifold3d), собираются одной командой, проверяются и выдаются в STEP, STL и 3MF вместе с PNG-превью. Печатаете вы сами: открываете файл в Bambu Studio.

Удобнее всего работать через Claude Code: откройте эту папку и напишите, например, «сделай держатель под …» или «доработай этот STL: …». Порядок работы описан в скилле [.claude/skills/cad](.claude/skills/cad/SKILL.md) и в [CLAUDE.md](CLAUDE.md).

## Установка

Нужен только [uv](https://docs.astral.sh/uv/). Python 3.12 и пакеты он поставит сам внутрь папки проекта:

```bash
uv sync
```

```bash
uv run pytest
```

Первый запуск после установки может идти несколько минут: Windows Defender проверяет новые файлы. Дальше одна сборка занимает секунды.

## Команды

| Команда | Что делает |
|---|---|
| `uv run cad.py new part <имя>` | создать `parts/<имя>/` из шаблона |
| `uv run cad.py new remix <имя> <файл>` | создать `remix/<имя>/`: оригинал копируется в `source/` только для чтения, сразу печатается `inspect` |
| `uv run cad.py build <папка>` | собрать: STEP, STL, 3MF, PNG и отчёт проверок в `<папка>/out/` |
| `uv run cad.py preview <папка или файл>` | только PNG (`--section x/y/z` добавляет разрез) |
| `uv run cad.py check <файл>` | проверки любого STL, 3MF или STEP, в том числе чужого |
| `uv run cad.py inspect <файл>` | габариты, объём, тела, основание, плоские грани |

Для разовой сборки с другим соплом или пластиком: `--nozzle 0.6`, `--material petg`.

## Как добавить деталь

1. `uv run cad.py new part phone-stand`
2. В `parts/phone-stand/model.py` задать параметры вверху (мм) и геометрию в `build(p)`. Зазоры брать из `p`, отверстия под винты — из `cadlib.fasteners`. Образец: [parts/example-bracket](parts/example-bracket/model.py).
3. `uv run cad.py build parts/phone-stand`, посмотреть `out/phone-stand.png` и отчёт.
4. Открыть `out/phone-stand.3mf` (или STL) в Bambu Studio и проверить, что нет предупреждений о сетке, затем печатать.

## Как доработать чужую модель

1. `uv run cad.py new remix holder-fix C:\Users\<вы>\Downloads\holder.stl`
2. Вписать в `remix/holder-fix/SOURCE.md` ссылку, автора и лицензию.
3. В `remix.py` описать правки через `cadlib.mesh`: `subtract` (отверстия, пазы), `add`, `cut`, `scale`. Образец: [remix/example-stub](remix/example-stub/remix.py).
4. `uv run cad.py build remix/holder-fix`. Отчёт сравнит результат с оригиналом и проверит, что сам оригинал не изменился.

Чужие файлы из `remix/*/source/` в git не попадают.

## Проверки при сборке

1. Сетка замкнута и manifold, нет вырожденных треугольников. **Ошибка.**
2. Объём больше 0; число тел совпадает с ожидаемым. Объём ≤ 0 — **ошибка**, лишние тела — предупреждение.
3. Деталь влезает в стол 256 × 256 × 256 с запасом 5 мм. **Ошибка.**
4. Масштаб правдоподобный: размер от 5 до 1000 мм. Иначе предупреждение: возможно, модель в дюймах или метрах.
5. Есть плоское основание. Если его нет, предупреждение.
6. Доля нависаний круче 45°, для информации.
7. Для ремикса: изменение объёма и габаритов относительно оригинала, хэш оригинала.

Если не прошла хотя бы одна **ошибка**, `build` завершается с кодом 1.

## Допуски и калибровка

Допуски, профили сопел (0.2 / 0.4 / 0.6 / 0.8) и пластиков (PLA, PETG, ABS, ASA) лежат в [printer.toml](printer.toml). Значения стартовые. Чтобы подогнать их под свой принтер, напечатайте `calibration/` (`uv run cad.py build calibration`) и следуйте [инструкции](calibration/README.md).

## Структура

```
cad.py              CLI
printer.toml        принтер, сопла, пластики, допуски
cadlib/             export, preview, checks, info, fasteners, mesh, config
parts/<имя>/        детали с нуля: model.py, README.md, out/
remix/<имя>/        ремиксы: source/ (оригинал), remix.py, SOURCE.md, README.md, out/
calibration/        образец допусков
templates/          шаблоны для new part / new remix
tests/              pytest
```

## Через Telegram (multiclaude)

Мастерская ставится как аддон в [multiclaude](https://github.com/korsicheg/multiclaude), Telegram-бот, где у каждого свой Claude Code. Тогда деталь можно заказать из чата, а ассистент пришлёт PNG-превью и 3MF. Установка описана в [multiclaude/addon/README.md](multiclaude/addon/README.md). На сервере с Ubuntu нужен ещё `libgl1`, его ставит `setup` аддона. Сборка на слабом ноутбуке занимает 10–60 с и до 0.7 ГБ памяти, чужая модель на миллион треугольников — до 1.2 ГБ.

## Чего здесь нет

Нет связи с принтером, слайсинга, скачивания по ссылке и многоцвета (AMS). Скрипты не выходят в сеть, это проверяет тест.

## Лицензия

Код распространяется под лицензией [MIT](LICENSE). Она не распространяется:
- **на лого мастерской** (сиба-ину с бабочкой). Это личный знак владельца: картинка и контуры лого в репозиторий не входят, а использовать лого без разрешения нельзя. Без данных лого `cadlib/logo.py` собирает детали без него, и тесты лого пропускаются;
- **на ремиксы чужих моделей**: у каждой модели своя лицензия, она указана в `SOURCE.md` ремикса.
